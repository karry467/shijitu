# 史迹图 — 基于《史记》的交互式数据可视化平台

> **TRAE AI 创造力大赛参赛作品** · 由 TRAE Work AI 原生工作台深度协作打造

---

## 一、项目简介

**史迹图**是一款以《史记》为核心内容、面向现代读者的交互式数据可视化平台。我们将卷帙浩繁的史学经典转化为**人物关系网络、事件时间轴、时空地理地图、典故知识图谱**等六大可视化维度，让两千年前的历史跃然屏上。

本项目从数据构建到代码实现，从交互设计到视觉打磨，全程由 **TRAE Work（AI 原生工作台）** 深度参与协作完成。AI 不仅承担了海量结构化数据的生成与清洗，更参与了前端架构设计、复杂图表编码、Bug 修复与性能优化，探索了 "人类创意 + AI 工程" 的全新创作范式。

---

## 二、作品亮点

### 1. 六大可视化维度，一图胜千言
将《史记》中的人物、事件、地点、关系、典故等多元数据，分别映射为关系图谱、时间轴、地理地图、雷达图、桑基图、词云等可视化形态，大幅降低历史阅读门槛。

### 2. 全栈 AI 协作，从 0 到 1 的革新实践
数据层（105 篇章结构化抽取）、前端架构（8 页面路由设计）、交互逻辑（图表联动与筛选）、安全加固（XSS 与注入防御）、美术风格（古典配色与字体），均有 AI 的深度参与。

### 3. 零构建、零依赖部署
纯前端技术栈，无需 Node.js、无需打包工具，双击 `index.html` 即可运行。所有第三方库均离线托管于 `lib/` 目录，真正做到开箱即用。

### 4. 电影级交互细节
支持深色/浅色主题一键切换、全站键盘快捷键导航、页面间参数联动跳转、悬停微动效与过渡动画，让历史探索如同操作现代 Web App 般流畅。

### 5. 可扩展的数据架构
采用扁平化 JSON 数据层设计，预留了清晰的字段规范与扩展接口。未来可轻松接入《左传》《战国策》《汉书》等更多典籍。

## 三、功能概览

| 页面 | 功能描述 |
|------|----------|
| **index.html** | 首页与篇章索引。支持全局搜索人物、事件、地点、典故；105 篇章卡片式浏览，一键直达详情。 |
| **detail.html** | 详情页。展示单个人物/事件/地点/篇章的完整信息，包含生平、性格、名言、史记原文摘录及相关推荐。 |
| **graph.html** | 人物关系图谱。力导向图展示 242 位历史人物、190 组关系网络；支持按篇章与关系类型筛选，点击节点查看详情。 |
| **timeline.html** | 事件时间轴。ECharts 散点图串联 178 个关键事件；支持按篇章筛选，点击事件查看时间、地点、结果与原文。 |
| **map.html** | 时空地图。Leaflet 地图标注 130 个历史地点；古今地名对照，点击地点查看相关事件列表与经纬度信息。 |
| **idioms.html** | 典故探源。词云与卡片展示 180 个出自《史记》的经典典故；支持出处溯源与原文对照。 |
| **dashboard.html** | 数据总览。仪表盘汇总全书数据规模，包含人物分布、事件趋势、关系类型占比等多维度统计图表。 |
| **compare.html** | 人物对比。支持两位历史人物的多维度雷达图对比、核心能力条形图对比与关键战役时间线对照。 |

## 四、AI 协作过程

本项目是 "人类导演 + AI 执行" 创作模式的完整实践，AI 在以下五个阶段均发挥了核心作用：

### 阶段一：数据层构建
- **数据生成**：AI 基于《史记》原文，自动提取并结构化生成 105 篇章、242 人物、178 事件、130 地点、190 组关系、180 个典故的完整数据集。
- **数据清洗**：AI 编写 `check_data.py` 校验脚本，自动检测 JSON 格式错误、字段缺失、关系悬空、经纬度越界等数据质量问题，并输出修复建议。
- **关联补全**：AI 自动为人物、事件、地点建立交叉引用索引，确保详情页能够准确推荐"相关人物"与"相关事件"。

### 阶段二：前端架构
- **页面规划**：AI 根据功能需求，设计 8 个独立 HTML 页面的信息架构与导航体系。
- **组件抽象**：AI 提取公共样式（`common.css`）、主题引擎（`theme.js`）、快捷键模块（`shortcuts.js`），实现跨页面复用。
- **路由与传参**：AI 设计 URL Query 参数协议，实现页面间的数据联动（如从图谱点击人物 → 跳转详情页并自动加载对应 ID）。

### 阶段三：交互优化
- **图表实现**：AI 使用 ECharts 编写了力导向关系图、时间轴散点图、雷达对比图、桑基图、仪表盘等多种复杂可视化组件。
- **地图集成**：AI 集成 Leaflet + 高德地图瓦片，实现 130 个历史地点的标注、弹窗与筛选联动。
- **响应式适配**：AI 为所有页面添加移动端适配逻辑，确保在手机浏览器中依然可以流畅浏览图谱与地图。

### 阶段四：安全修复
- **XSS 防御**：AI 识别出早期版本中 innerHTML 直接插入用户可控数据的风险，全面替换为 `textContent` 与转义函数。
- **输入校验**：AI 为 URL 参数、搜索框输入添加正则校验与长度限制，防止注入攻击与异常数据导致的页面崩溃。
- **边界处理**：AI 补充了大量空值判断与 try-catch 包裹，提升极端场景下的页面稳定性。

### 阶段五：美术设计
- **视觉风格**：AI 提出"暖米色背景 + 深褐文字 + 朱红点缀"的古典配色方案，营造古籍阅读氛围。
- **字体选择**：AI 推荐使用 Noto Serif SC 宋体作为标题字体，增强文化厚重感与历史沉浸感。
- **微交互动效**：AI 为卡片、按钮、图表节点设计了统一的悬停放大、阴影过渡、渐变动画，提升整体质感。

## 七、交互细节

- **主题切换**：全局支持深色/浅色模式一键切换，由 `theme.js` 统一管理 CSS 变量与 localStorage 持久化。
- **键盘快捷键**：`shortcuts.js` 提供全站快捷键支持，如 `?` 呼出帮助、`Esc` 关闭弹窗、`/` 聚焦搜索框等。
- **响应式布局**：基于 Tailwind CSS 的断点系统，完美适配桌面端、平板与手机浏览器。
- **微交互**：统一设计悬停放大、卡片浮起、按钮涟漪、图表节点高亮、页面转场过渡等动效。
- **全局搜索**：首页支持跨维度实时搜索，输入即搜，结果按人物、事件、地点、典故分类展示。
- **页面联动**：任意页面点击人物/事件/地点卡片，均携带 ID 参数跳转至详情页，实现全站无缝导航。

## 八、快速开始

### 方式一：直接打开（推荐）
本项目为零依赖纯前端项目，双击打开 `index.html` 即可在浏览器中运行。

### 方式二：本地服务器（解决跨域限制）
若部分浏览器对本地文件访问存在限制，可使用以下命令启动本地服务器：

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js
npx serve .
```

然后在浏览器中访问 `http://localhost:8000`。

### 浏览器兼容性
- Chrome / Edge / Firefox / Safari 最新版
- 支持移动端浏览器访问
